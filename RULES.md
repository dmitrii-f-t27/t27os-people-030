# Release QA rules

1. Check first: before a future fix, save a small failing reproducible check, exact source/binary hash and scope. Split lightweight work; run heavy builds/tests sequentially; retry only the affected checks. Never fabricate an earlier red execution.
2. Preserve working results: change only required `.t27` logic, keep prior binaries/evidence and foreign work, and verify directly affected native paths. Public source distribution is not canonical upstream permission.
3. READ activation: the bridge may consume ACTIVE before the chat driver. Both paths must share authenticated activation exactly once, reset retry without downgrading DELIVERED/READ, and propagate status into persistence. The observed missing reverse READ and targeted recovery probe are separate evidence; the original first-loss cause was not established.
4. Unseen READ: Connection/settings, detached/hidden/minimized views and closed in-call chat must not mark new text read. Synchronize actual eligibility before transport polling and activation/reattach. Candidate11 was identified by retrospective source review; candidate12 exercised real callbacks22/23 and native Back. Do not relabel source review as an old-app runtime red test.
5. State has one owner: QA must read authoritative bridge visibility, never reuse a UI video-associated slot. Candidate12 produced diagnostic34 during video; the explicit collision assertion failed before removal of duplicated state in13. Preserve that red log and verify closed/open in-call chat on the actual new binary.
6. Native selectors: candidate09 crashed on unsupported NSColor resolvedColorWithAppearance:. Check unfamiliar AppKit selectors against actual runtime/SDK before rebuild; use supported native separators and semantic colors.
7. Screenshot fidelity: inspect actual native narrow/wide layouts, long Russian labels, row/avatar separation, icon positioning and preserved Advanced actions. Use genuine route/state evidence. Capture calls only with explicitly labeled synthetic source2 and camera/microphone capture off; never publish real-camera images from private tests.
8. Ephemeral identities: use a fresh isolated QA home per RAM identity. Existing peer-only history filenames do not namespace a replaced local identity; reusing a QA home can collide message sequences. Preserve old homes; do not claim migration or at-rest encryption.
9. File insertion: exercise real NSOpenPanel; validate size before and after UTF-8 reading, preserve the draft on failure, insert without automatic send, and clear the test draft. This is text insertion, not binary file transport.
10. Delivery: pin final source/artifact hashes and clearly label prior-candidate screenshots. Check READ, real duplex counters, own preview, mute/camera controls and End on the changed binary. Keep upstream registry prerequisites and protected keys separate; do not self-merge or tag a GitHub Release.
